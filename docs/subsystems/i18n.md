# 文案与语言（#32）

界面说哪种语言、每一句话从哪来。跨 Go 与页面两侧：原生菜单、文件对话框、
跳过的文件原因、错误都从同一份目录读；页面的静态标记、动态渲染和 aria
标签也都读它。

## 职责边界

| 文件 | 管什么 | 不管什么 |
| --- | --- | --- |
| `locales/zh-Hans.json` | 源语言：所有 key 与文案；`@key` 声明占位符类型 | 不写代码 |
| `locales/en.json` | 英文译文；key 集合必须与源语言完全一致 | 不改接口 |
| `locales/catalog_gen.go` | `generate` 写出：`In(locale)`、每个 key 一个方法 | 不手改 |
| `src/locales.ts` | `generate` 写出：`messagesIn(locale)`、类型化方法 | 不手改 |
| `src/i18n.ts` | 选择语言、`setLanguage()`、填写 `data-i18n*`、稳定错误码 | 不存设置 |
| `i18n.go` | Go 侧 `tr()`、应用的语言列表 `appLanguages`、语言解析、错误码常量 | 不翻译页面 |
| `mygo.config.ts` | `i18n: { dir, source }`，驱动校验与生成 | 不写文案 |

`Settings.Language`（`"system" | "zh-Hans" | "en"`）是唯一的状态；它和其他
设置一样进 `settings.json`，默认 `"system"`，不变量 4 不变。

## 运行路径

1. `mygo generate` 校验目录（缺 key、占位符不一致、ICU 解析失败都会拒绝），
   再写出 `locales/catalog_gen.go` 与 `src/locales.ts`。
2. Go：应用就绪时 `resolveLanguageNow()` 按设置解析一次；`SaveSettings`
   发现 `Language` 变了就 `changeLanguage()` 重新解析并调用
   `setLanguageListener`，`main.go` 用它在同一个回调里重建应用菜单与托盘
   菜单。跟随系统时桌面语言变了，`app.OnLocaleChanged` →
   `followDesktopLanguage()` 走同一条重建路径。之后所有 `tr()` 调用（对话框、
   跳过原因、错误、生成的文件名）自动换语言。
   选定的语言还会交给 MyGo（`App.SetLocale`）：它自己贴标签的菜单项
   （关于、隐藏、退出、编辑与窗口菜单）、系统对话框按钮与 AppKit / WebKit /
   GTK 的自带文案都按它换。跟随系统时启动不碰 MyGo——它显示的就是桌面的
   语言，或者用户在系统里单独给 AnyPic 设的语言，那不该被我们清掉；用户从
   固定语言切回「跟随系统」时才把之前交出去的选择收回来（`SetLocale("")`）。
3. 页面：`syncSettingsToUI()` 是唯一入口——它 `setLanguage(settings.language)`
   并填写静态标记。快照、后端返回、demo 初始化、用户改语言都会经过它；
   `renderAll()` 随后重画动态文本。`onLocaleChange` 只在设置为
   `"system"` 时重新解析并重画。
4. 系统语言只解析一处：`main.go` 用 `app.SetLanguages(appLanguages...)`
   告诉 MyGo 应用说 `en`、`zh-Hans`、`zh-Hant`，MyGo 按桌面语言在其中挑
   一个（`App.Locale`）。Go 的 `resolveLanguage("system")` 与页面的
   `systemLanguage()`（`mygo.locale`）读的都是这个答案，再映射到目录：
   `zh*` → `zh-Hans`，其余 → `en`。列表的形状就是规则本身——英文在前，
   所以一种都不认识的桌面得到英文而不是源语言；列出 `zh-Hant`，所以繁体
   桌面（通常第二语言是英文）解析成中文而不是英文。浏览器预览没有 MyGo，
   退回 `navigator.languages`。

## 状态转换

| 从 | 事件 | 到 |
| --- | --- | --- |
| 任意 | 用户选「跟随系统」 | `Language="system"`，按桌面语言解析 |
| 任意 | 用户选中文 / English | 固定该语言，直到再次更改；同时交给 MyGo |
| 任意 | 用户选「跟随系统」 | 收回交给 MyGo 的选择，按桌面语言解析 |
| 固定语言 | 桌面语言变化 | 不变（显式选择优先） |
| 跟随系统 | 桌面语言变化 | 页面重画；Go 重新解析并重建菜单与托盘 |
| 旧设置没有 `language` | 启动 | 归一化为 `"system"` |

## 约束

- **文案只在目录里。** 页面标记写 key（`data-i18n`、`-title`、`-aria`、
  `-placeholder`、`-alt`、`-content`），脚本写 `t.<key>()`，Go 写
  `tr().<key>()`。守卫会按字符串字面量扫中文，注释不算。
- **动态文本不挂 key。** 由数据决定的元素（`#emptyTitle`、`#batchStatus`、
  行内按钮、预览标题/详情）只由渲染函数写；否则 `applyText()` 会在语言变化
  时把它们冲掉。
- **活得比一次语言切换久的元素要能重贴。** 队列行建一次就复用，行上控件的
  标签由 `labelRow()` 施加，`updateRow()` 发现行的语言与页面不同就重贴；
  不要在 `createRow()` 的模板里直接写 `t.<key>()`。
- **系统语言只解析一处。** 页面、Go 与 MyGo 自己贴标签的菜单项都读
  `App.Locale` 这一个答案；不要在 Go 或页面里再各写一套「按桌面语言挑
  语言」的规则——两套规则在繁体桌面和没有对应目录的桌面上会给出不同语言。
- **交给 MyGo 的选择它会记下来。** `App.SetLocale` 把语言存成应用语言：
  macOS 存进应用自己的 defaults（「系统设置 → 语言与地区 → 应用程序」里
  能看到 AnyPic 这一项），Windows / Linux 存成 `PathUserData/locale`。这与
  `settings.json` 的 `language` 一致，是对用户显式选择的登记，不是第二份
  设置；`settings.json` 仍是唯一来源，每次启动按它重新交一次。
- **页面认码不认字。** `anypic:capture-canceled`、`anypic:capture-busy`、
  `anypic:screen-permission`、`anypic:no-clipboard-image` 是协议，永远不翻译；
  页面在 `src/i18n.ts` 的 `errorCodes` 里引用，Go 在 `i18n.go` 里定义。
- **占位符类型写在目录里。** 纯 `{n}` 默认是 String；要 `int` 就在源语言的
  `@key.placeholders` 里声明，否则生成的 Go/TS 签名对不上。
- **生成物不手改。** `src/locales.ts` 与 `locales/catalog_gen.go` 的文件头
  写明 `DO NOT EDIT`；改文案 = 改 `locales/*.json` 再 `bun run generate`。
- **系统给回来的错误前面要有我们自己的话。** 操作系统和 MyGo 的错误只说
  它们自己的语言（`permission denied`、`mygo: allow AnyPic to open at
  login…`、`context canceled`）。返回给页面前用
  `fmt.Errorf("%s: %w", tr().<key>(), err)` 把目录里的一句话放在前面，原因
  留在后面；管线里的取消走 `errorText()`。还没有前缀的只剩系统对话框本身
  打不开（`AddPaths`、选输出目录、导出时的对话框）和打开发布页失败这几条
  少见路径。
- **一种语言一个文件。** 新增语言 = 新增 `locales/<tag>.json` 并在
  `#languageSeg` 加一个按钮；`appLanguages`、`catalogFor`（`i18n.go`）与
  页面的 `systemLanguage()` 也要认识它。

## 验证

```sh
bun run generate         # 目录校验 + 生成
bun run typecheck
go vet ./...
go test -race ./...      # TestIssue32* 守目录、标记、字面量与设置
bun run dev:web          # 940×640，亮/暗 × 中/英 各过一遍
```

测试证据：

- `TestIssue32CatalogsHoldEveryLanguage`：key 集合、ICU 解析、占位符、
  英文不得含中文。
- `TestIssue32MarkupUsesTheCatalog`：`index.html` 无中文字面量、每个 key
  两种语言都有、`#languageSeg` 三个选项。
- `TestIssue32NoHardcodedCopy`：`src/*.ts` 与根目录 `*.go` 的字符串字面量
  不含中文（生成物除外）。
- `TestIssue32LanguageIsASetting`：`Settings.Language`、默认值、菜单读目录、
  页面绑定 `#languageSeg`。
- `TestIssue32LanguagesResolveFromTheDesktop` / `...GoSaysItsCopy...` /
  `...SettingsChooseTheLanguage`：解析顺序、Go 运行时换语言、错误码稳定。
  解析表把桌面语言喂给 MyGo 自己的匹配器（`i18n.Match`），所以每一行也是
  页面看到的结果。
- `TestIssue32OneAnswerForPageMenusAndGo`：`appLanguages` 的形状、`main.go`
  把它交给 MyGo、页面仍读 `mygo.locale`、Go 不再自己走桌面语言列表。
- `TestIssue32GoFollowsADesktopLanguageChange`：跟随系统时桌面语言变化会
  重新解析并只重建一次菜单；显式选择不跟随。
- `TestIssue32QueueRowsFollowALanguageChange`：队列行的标签不写死在
  `createRow` 里，由 `updateRow` 按语言重贴。
- `TestIssue17PageHandlesScreenPermission`：权限文案仍在目录里且覆盖
  「屏幕与系统录音 / 旧名 / 开关已开 / 删掉重加 / 重启」。
